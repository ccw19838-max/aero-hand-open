# V2：先学习多指握持，再准备转笔

这是2026-11-11新增的主动握持实验，原转笔任务和首次失败报告保留。用户授权先学习多指握持，因此握持训练不再要求先有一个被动静态握稳的参考姿态。

相关 GitHub 项目的奖励、握姿生成与实机姿态估计源码对照见 [多指握笔调研与适配建议](pen_grasp_github_references.md)。该调研记录候选改进，不改变本轮冻结的训练配置。

## 训练入口与初态

```bash
cd /workspace/aero-hand-open
PEN_PYTHON=/workspace/.venvs/aero-rl-reference/bin/python
"$PEN_PYTHON" -m experiments.pen_spin.grasp_prepare \
  --output experiments/pen_spin/artifacts/grasp-release-new
"$PEN_PYTHON" -m experiments.pen_spin.train \
  --reference experiments/pen_spin/artifacts/grasp-release-new/reference.npz \
  --output experiments/pen_spin/artifacts/grasp-train-new
```

准备过程保留130mm/16g配重笔、竖直右手、重力、摩擦和原关节/腱绳。搜索手指预形状和靠近三个指尖的笔姿态；笔仅在回合重置时放置，释放后不使用外力、支架或位置固定。初态不得有无效支撑或超过0.2mm的初始穿透，还需在干净的原生MuJoCo状态中存活100ms，不出现支撑或超过1mm的穿透。该检查给策略留下控制机会，不要求它已经稳定握住。

准备报告使用 `grasp_reset_ready` / `grasp_acquisition_only`，并明确 `stable_grasp:false`。只有 `task_mode:grasp` 的训练可以接受该报告；它不能用于绕过转笔的准备门槛。

当前正式运行目录为 `artifacts/grasp_release_v4` 和 `artifacts/grasp_train_v4`（均位于 `experiments/pen_spin/` 下）。前面的v2/v3尝试由于初始支撑或扰动敏感而在编译阶段中止，不作为学习结果。它们的零步初始化参数不是训练好的权重。

正式运行起钟时间为北京时间2026-11-11 09:28:58，含最终评估的截止时间为11:28:58。20个小扰动初态的无动作预检均存活150ms。PPO已完成实际参数更新：2,048步快照在20个验证种子上的早期原生MuJoCo检查成功0/20，17次穿透超限、3次无效支撑，尚未稳定握持。该检查不用于课程晋级；数据位于 `grasp_train_v4/early_policy_check/`，训练仍继续。实时步数以 `live_status.json` 为准。

## 握持规则与奖励

- 7维动作仍每50ms改变执行器目标，增量不超过有效量程±5%。物理子步仍为2ms。
- 初期位置扰动为±10μm、角度扰动为±0.01°，便于先学会控制；这不代表已通过毫米级扰动测试。
- 多指握持要求拇指加至少另外两根不同手指，法向力均≥0.02N。
- 笔线速度<0.03m/s、角速度<0.5rad/s，在80mm工作区域内，连续保持1秒才成功。
- 允许起步300ms尝试接触；之后连续完全脱手超过150ms失败。支撑、明显穿透及数值异常不享受起步宽限。
- 握持阶段不计算转角，也不要求拇指保持转笔参考轴姿态；为转笔准备时必须重新检查这些条件。工作区中心取笔的初始中心。

独立奖励版本为 `schema_version:2,task_mode:grasp`：每子步奖励为

```text
dt * [2*sum(exp(-指尖到笔表面距离/0.015))
      +3*有效接触手指数 +5*满足多指接触 +20*满足稳定保持
      -2*线速度范数² -0.1*角速度范数² -0.02]
 +50*成功 -30*失败
```

仍有每控制周期 `-0.2*dt*mean((a-a_prev)²)` 的动作变化惩罚。接近和接触只提供学习信号，不能代替成功条件。

## 预算、状态和下一阶段

本轮只训练握持，预算2小时，包含准备、编译、训练和评估；预留最多10%的剩余时间用于独立评估与录像。CPU网络、PPO参数、8个训练环境及4个验证环境沿用基线。

每30分钟在固定20个验证种子上评估，连续两次成功率≥80%才认为握持课程通过。当前扰动较小，之后需扩大扰动复核。未达标不进入旋转。结束时的100回合独立评估使用握持目标0°，不得把握持成功写成360°转笔成功。

`live_status.json` 提供运行阶段、累计训练步数、最近验证和检查点位置。`stages/hold/last/metadata.json` 的 `training_steps:0` 只是初始化参数；步数大于0才表明已经进行PPO更新。学习效果仍以验证成功率为准。

新增握持规则、门槛隔离及原任务回归测试共运行47项，其中46项通过、1项可选完整MJX测试跳过。正式训练已实际完成8环境CPU PPO更新，并检查了训练权重及归一化状态均为有限值。

握持达标后的下一步，是从成功轨迹提取握姿，验证它是否满足绕拇指几何约束和2ms/1ms一致性，再以握持权重初始化90°课程。如果只有主动控制才能握稳，也需验证该控制器的交接，不能冒充被动静态参考。当前握持模式会停在这一关，不直接跳过转笔的检查。
