## 运行条件与模型检查

- CPU：5个可用逻辑CPU，无GPU；Python3.10.22、JAX/JAXLIB0.6.2、Brax0.13.0、MuJoCo/MJX3.3.6。
- 右手根节点使用指定位置与−90°Y旋转，重力保持向下，原关节/腱绳/执行器保留。
- 笔长130mm、直径10mm、质量16g；重心偏向A端6.875mm，惯量为指定数值。视觉几何不计质量；胶囊体碰撞，实际接触滑动摩擦0.6、接触维数3。
- 完整Aero手模型中的诊断接触力：Native **3.062690N**、MJX **3.061642N**。这是固定诊断位姿的接触测试，不是有效握持证据。
- 2ms/1ms自由运动比较：0.1秒后位置差 **0.4905mm**，速度差约`5.55e−16`；通过预设1mm门槛。
- 实际拇指轴偏差30°、中点横向偏差10mm作为本版“明显偏离”的明确门槛，均使用0.1秒失败锁存。

## 失败视频与数据

| 文件 | 内容 |
|---|---|

| `diagnostic_trajectory.npz` | 15,000个真实2ms物理子步的笔/手状态、接触与任务轨迹 |
| `diagnostic_report.json` | 无策略、未批准初态、物理时长及失败事件说明 |
| `video_trajectory.json` | 帧时间、回合及重置标记 |
| `preview.png` | 首帧预览 |

该视频使用第一个**未批准**的搜索初态，每10秒重复一次，执行器目标固定。三个回合均在首个2ms子步因无效支撑锁存失败；之后继续物理模拟以显示掉落过程。它不是选出的“最佳策略”，也没有使用训练权重。

NPZ中 `physical_seconds` 是连续物理时间，`episode` 标明重置；`trace` 的 `time` 为任务计时，失败锁存后停止。物理状态仍继续记录，因此分析失败后的运动应使用 `physical_seconds`。
