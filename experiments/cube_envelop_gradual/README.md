# 16 小时小角度课程：先 Z，再重点训练 X/Y

这是独立实验，旧 `cube_envelop`、`cube_reorient` 源码及检查点不改。保留 57 mm、77.966253 g 魔方、原约 20° 掌面倾角、原腱绳/关节/摩擦/质量。继续使用原生 MuJoCo、4 个 CPU 环境、78 维观测和 7 维动作（每周期最多调整有效量程 1%）。

实际运行见 [long16h_z_then_xy_v1/status.json](artifacts/long16h_z_then_xy_v1/status.json)。预算是从启动起最多 **16 小时**、**5,000,000 个环境步**，包含训练前对照和验证时间。当前机器先前吞吐约 50 步/秒，步数上限高于 16 小时预计采样量，不再受旧实验的 2 小时/50 万步限制。

## 顺序与升级

1. 先训练固定手坐标 **Z**，最多占用前 2 小时；若提前完成 90° 阶段，则提前进入 X/Y。
2. 剩余时间重点训练 **X 和 Y**，每回合均匀选择其中一个轴。两个轴有独立的目标角度和升级记录：X 达标可以升级，Y 保持自己的当前角度，反之亦然。
3. Z 超过 2 小时仍未到 90°，也会保存其最好检查点并进入 X/Y，避免阻塞主要任务。
4. 若 X/Y 提前完成独立验收，而 Z 尚未完成，剩余时间才返回补练 Z。Z 与 X/Y 的已验证检查点分别保留；不把一个轴的成绩当成另一轴的成绩。

角度顺序为 **5° → 10° → 15° → 30° → 45° → 60° → 90°**。

| 目标角 | 姿态误差及有向进度容差 |
|---:|---:|
| 5° | ±1° |
| 10° | ±2° |
| 15° | ±3° |
| 30° | ±6° |
| 45° | ±9° |
| 60°、90° | ±10° |

每 32,768 环境步，对当前训练轴分别评价 20 个固定初态。一个轴连续两次成功率达到 90%，才升级该轴。最终 90° 阶段验证通过后，再做每轴 100 回合独立检查（起始种子 50000000）。小角度通过只说明该角度能力，不能称为完成 90° 翻面。

## 成功条件与奖励

沿用五指课程：先建立拇指、食指、中指、无名指、小指全部有效接触并低速保持 0.5 秒，再以此时实际姿态定义转动起点。转动时允许松指和换接触；到目标后必须恢复五指有效接触、低速连续保持 0.5 秒。目标按固定手坐标轴左乘四元数定义，使用完整姿态误差与累计有向转角窗口，不用欧拉单分量或魔方对称性代替。

初态不动无法通过 5° 目标：它与目标相差 5°，而容差只有 1°。完全失去手指接触时不奖正进度；反向进度仍扣，失联持续 0.15 秒失败。安装支架/地面、持续穿透、越界等原失败规则保持不变。

旋转势差奖励按当前目标角归一化。为避免 5° 目标仍使用旧 30° 接近奖励范围而给静止姿态过多分数，接近奖励宽度改为 `max(1°, min(30°, 目标角/3))`。目标之外的动力学和接触参数没有被修改。

## 权重与恢复

起点为已经通过独立 100/100 握持检查的旧 **65,536 步五指稳握权重**，而非直接延长失败的 90° 轨迹。加载前校验 78 维输入、7 维输出、源码与文件哈希、相同参考状态和物理配置。

课程换角度/换训练轴时复制策略与观测归一化统计，并重建优化器、重置该阶段采样计数；父状态累计所有阶段步数。同一阶段的 `--resume` 恢复策略、优化器与归一化，但不保证环境随机流逐位一致。每 8,192 步另存检查点，不需要等待较慢的完整分轴验证。

```bash
cd /workspace/aero-hand-open
/workspace/.venvs/aero-cube/bin/python -m experiments.cube_envelop_gradual.curriculum \
  --reference experiments/cube_envelop/artifacts/prepared_envelope_v1/reference.npz \
  --initial-checkpoint experiments/cube_envelop/artifacts/curriculum_envelope_v1/hold/latest \
  --output experiments/cube_envelop_gradual/artifacts/long16h_z_then_xy_v1 \
  --hours 16 --z-hours 2 --steps 5000000 --envs 4
```

已有同名运行时不要重复执行。若进程已停止，可使用相同参数再加 `--resume`，沿用原截止时间；若原监督器或子训练进程仍存活，会拒绝重复启动。

单独评估新检查点：

```bash
/workspace/.venvs/aero-cube/bin/python -m experiments.cube_envelop_gradual.evaluate \
  --checkpoint <阶段目录/latest> --output <新的评估目录> \
  --episodes 100 --axis all --video 30
```

`all` 指该检查点训练的轴集合（Z 阶段为 Z，X/Y 阶段为 X 和 Y）；可显式指定单轴。报告和录像显示各自真实目标角度，不把 5° 标成 90°。全局状态包括 `targets`、`passed_angles`、`axis_checkpoints`、当前阶段、累计步数、剩余时间。阶段目录中的 `status.json`、`progress.jsonl`、`latest` 和 `best` 用于核对具体成绩。

16 小时是预算，不是成功保证。到时保存权重与分轴失败数据；只有完整独立检查通过才能报告能力达标。新实验在当前分支本地运行，未推送、未发布。
