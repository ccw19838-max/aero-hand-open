## 最终标准

每次正式验证从原始批准的五指初握开始，随机的初态微扰和魔方颜色朝向使用未参与模型选择的种子。不得通过回合中移动物体、外力支撑、降低重力、修改尺寸质量或忽略失败来制造成绩。

两轴分别要求有向+90°±5°、完整姿态误差≤5°、拇指≥0.2N、其他四指各≥0.1N且不过大、线速度<0.03m/s、角速度<0.5rad/s，连续保持1秒。安装支架/地面支撑、持续穿透、越界、脱手失败条件继续生效。

为了把“完整实现”与偶然成功区分开，本轮只在**每轴、每种物理步长（1ms和2ms）各100个新的独立初态全部通过**后标记完成。课程的小角度成功和一条轨迹瞬时转到90°均不算最终成功；60小时到期未过关，记录未完成，不改写为成功。

## 初次调整

此前诊断已发现：X主动放松中指；旧缺指惩罚只在目标附近生效；较晚失败在gamma=0.99下的惩罚被明显折扣。Y曾达到30°验证65%，但后续策略退化。

- X从已验证五指初握的旧权重开始，先10°、20°等更细课程；转动全程加入接触恢复项和每指脱离时长的软惩罚，不强制五指全程贴住。策略观测由138维扩展至143维，新增五指脱离计时。
- gamma初值0.997，并增加停滞成本，减轻等待失败的偏好；保留实际五指终点要求。动作仍为每周期最多有效行程2%的增量。
- Y恢复已保存65%的30°版本，降低学习率，使用其真实成功的30°闭环轨迹做少量行为保持更新，减少遗忘。这些数据不被称为90°示范。
- 两轴都穿插15%的初握保持回合。验证始终固定目标，不混入这些辅助回合。
- 只迁移原策略及输入归一化。新增观测列零初始化，新的奖励/折扣设置使用新Value输出头、新优化器和新奖励统计，不声称逐位一致续训。

`config.py` 对每项可调整系数设定上下限，控制器不能通过调参放松最终标准。名义物理参数保持不变，本轮不以扩大物理随机化取代当前90°目标。

## 独立分段中的诊断调整

临时诊断也必须记录到 `operator_reviews/`，使用新分段和不可变的源检查点；三小时复查时刻和总截止时间不重置。

- `001_y_low_noise_retention`：在6个已知成功初态上，原教师的确定性推理为6/6；动作采样标准差0.03为6/6、0.08为4/6、0.25为0/6。这是选定初态上的探索噪声诊断，不是总体成功率。Y在 `segment_001` 恢复教师，初始采样标准差0.03、上限0.08，降低学习率并加强真实30°成功轨迹的行为保持。首次每步长20初态的完整验证仍为65%。
- `002_x_small_angle_precision`：原来的目标接近奖励宽度固定15°，在10°课程中，保持原位也能获得较高接近奖励。X在 `segment_001` 从较好的部分转动检查点继续；`shaping.py` 只将小于45°的训练目标接近奖励宽度改为 `max(5°, 目标角/3)`，握持目标0°和45°以上保持原式。观测、物理、终止和正式评估标准不变。初始探索标准差0.10，上限0.12。物理一致性测试检查相同动作下状态、观测和终止完全相同，仅训练奖励不同。
- `003_x_mount_margin`：窄奖励分段在16k、32k两次验证中，1ms/2ms每组均20/20次因支架支撑失败。四个选定初态的独立回放确认，X确实接触 `tetheria_mount_collision_0`（约0.541N）；手掌接触本来就是允许的。X在 `segment_002` 从16k较好的部分转动策略继续，只增加训练阶段靠近真实碰撞支架5mm内的软惩罚：`−2·实际步长·clip((5mm−间距)/5mm,0,2)²`。不参与碰撞的支架视觉网格被排除，避免对允许重叠的视觉模型误惩罚。姿态、力和支架接触失败标准不变；诊断见 `support_audit/REPORT.md`。
- `004_y_scaled_retention`：低噪声Y分段后期在旧成功轨迹状态上的动作均方偏差从约0.00035增至0.00227；验证曾降到50%，随后约60%，保护的最佳版本仍是65%。从最佳143输入教师重新收集12条真实成功轨迹，学习率降至2e−5，使用 `0.5×0.1×mean((动作偏差/0.03)²)` 做保持更新。该项明确改变克隆损失的尺度；相当于原始MSE系数约55.56，配置和检查点的 provenance 均记录该语义。不能把它与此前未归一化的0.1权重直接比较。
- `005_x_reachable_capture`：独立的短时物理预测控制从原始初握出发，曾达到姿态误差约0.95°，但五指稳定最长仅0.05秒，整个回合失败。截断后保持电机目标或使用固定负向修正，在1ms、2ms均未完成收稳。X在 `segment_003` 测试真实前缀辅助课程：非零目标训练回合有50%先实际回放上述轨迹的前28个控制动作，再由神经策略练习收稳；握持目标0°回合保持原入口。每次从原始初握真实模拟前缀，不写入中途物体状态，不用外力；无法合法执行完的前缀会被拒绝并记录。动作采样标准差0.03，上限0.05，降低学习率。辅助回合的成功不用于课程升级，所有课程/最终验证仍由神经策略独自从原始初握开始。
- `006_x_direct90` / `007_y_direct90`：首个3小时复查使用相同新初态比较当前与最佳：X10°均0成功，最佳模型平均最佳误差约1.06°；Y30°两者均65%，90°探测两轴均0成功。从已保留的较好模型开展直接90°目标试验，不把中间课程写成已通过。rollout从128增至256（每环境12.8秒采样窗口）、GAE lambda0.98、gamma0.999、进度系数40；探索标准差0.05，上限0.08。X停止使用辅助前缀；两轴训练从原始初握开始，仍穿插15%初握保持，正式验证固定90°。Y继续使用真实30°教师轨迹做保持；所有物理与最终五指1秒标准不变。原10°/30°检查点和评估完整保留。

报告必须分别标注瞬时最大角度、成功回合的最终角度和当前课程成功率。小角度验证允许±5°误差，30°课程中偶然抓稳34°不能被写成已经训练通过35°或45°课程。

## CPU读取优化

`fast_contacts.py` / `native_contacts.c` 只合并原来的接触读取循环；动力学积分、物理步长、动作映射、观测、奖励与成功/失败监控继续继承原实现。两种步长的完整状态、观测、奖励、结束标记与info逐步完全相同；已知Y轴30°成功轨迹、原生五指握持和真实地面接触检查均通过。原14项测试及新增3项等价测试已通过。

同一静态握持100控制周期的单次CPU基准测得1ms约1.16倍、2ms约1.51倍；这是微基准，不代表整个PPO训练的固定加速比。启用后沿用同分段、策略、优化器和奖励归一化状态，不重置学习。C源码、Python包装源码及MuJoCo版本的指纹写入goal/job/provenance；推理网络本身不依赖此读取优化。正式评估继续采用原Python环境。

默认仍可使用Python读取；当前目标通过 `native_contact_backend` 字段显式启用经过检查的C读取。源文件指纹与job不符会停止该启动，避免无记录地改变实现。

## 三小时复查

`controller.py` 负责独立进程，固定窗口内运行：

1. 观察两轴状态、当前和最佳检查点。每5分钟存档；训练内部也会定期验证课程。
2. 每个3小时复查点安全暂停采样并保存。对当前策略和同课程最佳策略使用相同验证初态公平比较；另做固定90°探测。
3. 当前成功率比最佳下降超过20个百分点时，恢复最佳策略，降低学习率/探索并增加行为保持强度。
4. 同课程连续两次复查没有成功、误差改善不到2°时，在新分段里加强接触恢复/停滞项。必要时测试直接90°目标，避免把更难的中间角度五指停稳当作永远不能跳过的门槛。此举不放宽最终目标。
5. 达到候选条件后进行独立100初态验证。通过的轴保存并停止更新，另一轴继续；两轴都通过才标记目标完成。

每次复查保存完整JSON和Markdown，包含前后指标、调整原因、源检查点和新配置。缺失的复查窗口标记“未观测”，不编造中断期间的数据。
