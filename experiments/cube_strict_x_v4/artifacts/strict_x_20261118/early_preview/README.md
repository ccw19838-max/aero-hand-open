# X 轴 5° 课程早期回放

V4 5° 课程的早期配对验证样例，从两种物理步长、各20个固定验证初态中选出。最终独立初态另行封存。

检查点完成了 32,768 个采样步。本例采用种子 7200011、2 ms 步长。严格成功要求在完整姿态和五指受力同时合格时保持 1.00 秒。

本例的瞬时转角峰值为 4.58°，首次违规前的有效峰值为 4.50°，目标保持最长 0.27 秒。首次违规在正式动作开始后 2.22 秒，当时角度 4.51°，越界手指为食指。

同一检查点在 1 ms 和 2 ms 配对验证中分别严格通过 0/20 和 0/20。

视频和逐帧轨迹记录了训练环境在奖励归一化前给出的本步得分和累计得分。本例 53 个控制周期合计 -10.169 分，逐步得分与实际训练工作进程完全一致。
