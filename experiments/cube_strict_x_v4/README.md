# X 轴单次翻面

在 20° 安装角的七电机右手上，拇指和小指推动 57 mm 魔方。食指、中指和无名指在正式动作中的每次 10 ms 采样都须分别保持 0.1–12 N。初握 0.25 秒后，从当时的魔方朝向确定 X 轴，沿该方向测量转角及相对质心的接触力矩，允许质心在工作区内移动。每个回合从原始握姿开始。

## 运行与恢复

在新 Linux 机器上继续训练，请使用 [GPU 迁移与续训指南](GPU_HANDOFF.md)。从交付包根目录运行以下命令，四个原生 MuJoCo 环境在 CPU 上采样，PyTorch 使用 CUDA 更新 PPO。

```bash
python -m experiments.cube_strict_x_v4.continue_training \
  --checkpoint checkpoints/x_latest --output runs/x_gpu --device cuda --updates 1024
```

已结束的 CPU 实验将配置和起止时间写入 [job.json](artifacts/strict_x_20261118/job.json)。[实验协议](artifacts/strict_x_20261118/protocol.json) 记录观测版本、力预警、奖励条款、源策略和核心源码校验值。历史验证数据中的检查点路径用于溯源，中间权重已精简。四个环境的物理步长依次为 1、2、1、2 ms。每次 PPO 更新采集 4 × 256 步，并进行 4 个训练 epoch。V3 使用 143 维输入。V4 追加三指的预测受力余量和三个预警标志。两组的七维初始动作、探索标准差和旧策略隐藏层一致。初态、物理参数和验证种子共用，独立验收另用封存的种子。

## 查看训练

- [训练状态](artifacts/strict_x_20261118/status.md) 给出当前课程、步数、正式验证和首个违规手指。逐初态 JSON 含两个推动指各自的推进与反向力矩冲量、有效峰值及预警统计。
- [脉冲对照](artifacts/strict_x_20261118/probe.json) 在三个初态、两种步长下分别记录静持、单指和双指短推。每个 10 ms 样本包含五指受力、力矩、切向速度、质心位移和角度。
- `evaluations/` 按训练步数保留验证与对应的不可变检查点路径。[V3 与 V4 对照表](artifacts/strict_x_20261118/comparison.md) 列出两个版本均完成的更新步数。`arms/v4/latest` 指向最近可续训检查点，含策略、优化器、归一化、采样状态和固定截止时间。
- [PPO 与恢复校验](artifacts/strict_x_20261118/engine_checks.json) 使用独立临时目录验证四路采样、初始化及跨保存恢复。

## 怎样判分

应本轮要求，X 轴训练从原 V4 检查点续训，课程依次为 **30°、60°、90°**。切换时保留策略、优化器、归一化状态和累计训练步数，从原始握姿开始新的 30° 回合。切换前的 5° 配对对照、5° 晋级和 10° 验证记录留作历史比较。[课程变更记录](artifacts/strict_x_20261118/amendment.json)

三个新阶段的角度容差均为 5°。有符号转角和完整三维姿态同时进入容差后，五指受力合格、线速度低于 0.03 m/s、角速度低于 0.5 rad/s，连续保持 1 秒才算成功。食指、中指或无名指首次受力越界时，锁定该回合的有效峰值。每回合的转角奖励最多 20 分，基于实际力矩和切向速度的推进奖励最多 8 分，两者均依赖新的有效进度。

每半小时分别用 1 ms 和 2 ms 物理步长，各跑 20 个固定验证初态。连续两轮中，每一轮两个步长都至少成功 16/20 才通过该阶段。若四次验证无改善，每个阶段最多用 10 分钟搜索可重放的三指补位动作。

三阶段共用本轮原有的 24 小时预算，最后 2 小时用于冻结策略、独立评估和录像。通过 90° 课程后，两个步长各 100 个封存初态全部成功才记录最终通过。若截止时仍在训练，`final/REPORT.md` 记录新课程已通过的阶段以及当前目标的独立测试结果，链接检查点、录像和轨迹。录像同时显示质心 X 轴、五指受力、推动指的力矩、首次违规和保持时间。
