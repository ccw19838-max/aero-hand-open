# X轴：拇指、小指推进；食指、中指、无名指稳定

按用户在 2026-11-17 观看 X 轴回放后的要求，新建独立 V3 实验。保留 V2 370,648 步暂停检查点、录像所选的旧拇指推进权重和只读 Y 权重。原任务模型与其代码不修改。

## 物理试验与边界

从原始握姿保持 0.25 秒后，食指、中指、无名指保持当前电机目标，仅向小指腱绳施加 +0.3、拇指外展执行器施加 −0.3 的归一化增量指令，执行 0.5 秒。2 ms / 1 ms 步长的峰值分别为 2.3462° / 2.3410°，三根稳定指在采样中均有效受力，拇指和小指均出现有效正向推动。详见实验目录的 `actuator_probe.json`。

这只证明一段小角度动作可行，不是 90° 完成。侧向力、正向力矩都来自原来的七个执行器、腱绳和碰撞摩擦；没有额外横向电机、外力或魔方状态注入。小指的“+”表示腱绳目标变化，不能直接理解为加大闭合力。

## 训练定义

- 食指、中指、无名指各自达到 0.1 N，且不超过 12 N，才算三指支撑有效。不能用其他手指替代其中一根。
- 任一稳定指失触立即进入补位模式；该状态下不支付正向姿态进度奖励。三指支撑连续失效超过 0.15 秒终止回合，原来的支架、地面、穿透、掉落等失败条件保持。
- 拇指和小指对魔方质心产生正向 X 力矩，并沿旋转切向运动且推进到新的角度，才获得推进附加奖励。静态挤压、反向力矩和重复来回刷角度不能得到该附加奖励。双指协同优于单指独推，但不要求两者力矩相等。
- 稳定指仍可学习小幅调整，没有锁死关节，也不使用脚本代替策略动作。七个输出均可学习。
- 观测沿用 143 维（包含五指力、距离、上一动作和仿真真值），修正的拇指根部分类和逐指距离顺序保留。阶段标记改为上述角色判断，任务版本独立。
- 在基本姿态奖励上增加三指接触/距离势函数、弱指不足代价和双指推进奖励。窄的到位奖励宽度随实际角度容差变化，避免小角度课程奖励原地不动。

每次从原始初握出发，不再使用已有两指脱离的 0.8 秒动作前缀。静态保持经过两组初态、两种积分步长校验（共 80 次，80 次成功）后，从 5° 开始。角度阶梯：5、10、20、30、45、60、75、90°。到位容差为 `min(5°,目标角/4)`；最终仍为 90±5°、完整姿态误差≤5°、五指在力门槛内、低速度连续保持 1 秒。

每 30 分钟以两种步长各 20 个固定初态评估当前课程，另做 X90 探测。连续两次在两种步长均达到 80% 才升级。90° 课程达标后，两种步长各 100 个未用于选模型的初态必须全部成功才宣布最终通过。3 小时使用额外初态审查。原地保持成功、小角度成功、单次峰值、训练窗口的受力占比均不是 X90 成功率。

## 参数与预算

使用旧最佳候选的隐藏特征，重新初始化动作头，避免继承主动伸开食指的动作。初始均值为 `[0,0,0,+0.15,-0.15,0,0]`，让小指和拇指在已验证方向上轻推；这是网络初值，不是持续覆盖策略的脚本。三根稳定指探索标准差为 0.04，驱动输入为 0.08–0.12，均设置上限。
