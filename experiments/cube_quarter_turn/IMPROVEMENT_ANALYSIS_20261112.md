# XYZ90停滞诊断与下一步实施顺序

本次分析没有更改运行中v1的奖励、物理参数或成功标准。原训练保留作对照；本次产物为真实环境的动作范围审计、映射对照、576条短控制序列搜索，以及下一版本的候选映射函数。

## 1. 已确认的问题

### 动作范围被参考握姿与固定scale的组合收窄

v1以很紧的57mm参考握姿为基准，却沿用官方围绕另一握姿设置的每通道scale。因此，归一化动作±1没有覆盖电机的全部有效量程。

| 通道 | 当前可达量程占完整范围 |
|---|---:|
| 食指腱 | 67.3% |
| 中指腱 | 77.1% |
| 无名指腱 | 69.9% |
| 小指腱 | 63.9% |
| 拇指外展 | 48.4% |
| 拇指腱1 | 40.4% |
| 拇指腱2 | 78.5% |

例如食指目标最高约0.09345m，而执行器上限约0.11039m；拇指外展最低约0.854rad，而有效下限为−0.1rad。不能仅通过增加网络输出或奖励权重访问缺失的区间。

下一版候选映射保持0为参考握姿，并分别缩放正负方向，使−1和+1对应实际上下限：

```text
a >= 0: target = reference + a * (upper - reference)
a <  0: target = reference + a * (reference - lower)
```

候选实现为`action_mapping_candidate.py`；它尚未接入运行中的v1。已有边界、零点和单调性检查。

### 策略已形成保守的“掌面静止”模式

固定同一个参考初态，使用同一Y轴检查点做映射对照：

| 指标 | 当前映射 | 完整行程映射 |
|---|---:|---:|
| 回合内最大正向转角 | 25.7° | 36.5° |
| 回合结束转角 | 17.0° | 16.9° |
| 最后拇指接触力 | 0N | 0N |
| 最后手指接触力之和 | 0.353N | 0.257N |
| 最后手部总法向力（含掌面） | 1.071N | 1.000N |
| 最后角速度 | 0.00088rad/s | 0.00352rad/s |
| 完整90°+1秒保持 | 未完成 | 未完成 |

放开行程增大了瞬间转动，但最终都停在约17°，主要由掌面支持，拇指已脱离。这是一个具体的局部策略，并非持续尝试大角度翻转。

初握手指法向接触力之和约32.7N，方块重量约0.765N；力之和不是合力，也不是可直接使用的摩擦裕量。它提示要检查预紧和换指空间。上述Y回放在最初约0.4秒还有很大的力峰，然后退化为掌面静止。

v1超时也结算−100，但gamma=0.99、12秒约240个控制步，远期−100的折扣值只有约−8.96。早期探索失败更昂贵，拖延失败有折扣优势；目前又没有真正完成奖励样本。这个机制会鼓励保守解。应将物理失败判据与训练惩罚尺度分开设计，不能只继续放大终局奖励。

### Actor缺少完整手部状态

Actor有7路手部反馈、历史动作、魔方真值和目标，但16个手关节的姿态/速度、指尖位置等主要在Critic输入中。欠驱动手在相同腱长下可能有不同的关节/接触组合，三维换指控制存在部分可观测问题。

当前目标允许仿真真值。下一版宜先训练全状态教师：加入被动关节位置/速度、指尖相对位置、实际电机目标、接触力幅值和显式动作阶段。等任务可行后再考虑只用编码器/视觉的状态估计与策略蒸馏。

## 2. 有预算的控制搜索结果

搜索使用真实`QuarterTurnEnv.step()`，保留2ms物理步长、原重力、尺寸、质量、摩擦、执行器限位、禁止支撑、穿透、工作区、接触与停稳条件。每个轴/映射96条带时间相关性的四阶段控制序列，共576条；每条含放松、推动、换指、捕获阶段。整个过程没有给物体外力或在轨迹中修改其位姿。

| 轴 | 现映射：失败前最佳有效角进度 | 完整行程：失败前最佳有效角进度 | 完整行程对应后续失败 |
|---|---:|---:|---|
| X | 19.7° | 37.4° | 越出工作区 |
| Y | 30.8° | 42.9° | 穿透超限 |
| Z | 27.4° | 49.0° | 接触安装座 |

表中“有效角进度”取合法支撑采样时有向进度与完整姿态误差改善的较小值，不把无支撑抛飞或错误轴转动算作进度。**这些高角度候选随后失败，不能当成成功演示。**

完整行程扩大了探索可见的转动范围，但2秒内未触发失败的候选反而更少：X为4/96、Y4/96、Z4/96；现映射分别为13/96、8/96、10/96。两组均没有90°并抓稳的成功轨迹。映射修正需要同时改进运动组织，不能直接等同于训练成功。

这只是一个参考初态上的有限短搜索。没有找到成功路径，不证明机械上不可能，也不能给出多初态成功率。

## 3. 推荐实施顺序

1. **修正动作映射并优化初握。** 新实验使用完整行程映射。分别为三个轴筛选支点和空闲手指，保留拇指+至少两指的可靠支撑，避免将所有手指高预紧夹死。降低不必要预紧、远离安装座，为中间旋转留出空间；不改20°安装倾角，不任意改质量/摩擦。
2. **先找确定性可达轨迹。** 用有显式支点/接触阶段的轨迹优化或MPC，先完成一条“放松→推动/滚过边→换指→捕获→保持”的90°轨迹。X/Y更应考虑滚动换支点，而不是在紧握位置原地硬扭。方块正方形截面转到45°时，投影可从57mm变为约80.6mm，需要额外总间隙约23.6mm；端点几何相同并不证明中间通道存在。
3. **用合格轨迹教策略，再做RL。** 收集可复现、无辅助、完整满足物理条件的示范，先做行为克隆，再用PPO增加扰动与鲁棒性。短的合法前缀只能用于准备/推动子技能，不能标成90°成功示范。不要只靠每50ms独立的动作噪声偶然凑出长换指序列。
4. **把旋转与捕获分阶段训练。** 旋转阶段保持90°目标，先学到达；捕获阶段从经过物理验证的近目标状态学习减速和抓稳；最后合并为完整90°+1秒任务。增加停滞检测和阶段相关奖励，避免放在掌面静止拖到超时。物理违规仍判失败；早期训练可降低失败奖励幅度，再逐渐恢复，而不是放宽物理判据。
5. **先分轴，后组合。** 三轴分别训练、保存最佳策略，避免把共享网络的相互影响与机械问题混在一起。先拿最有希望的一轴做完整样板（当前参考握姿下Y较有进度），再推广其余两轴，最终统一终态握持并验证连续执行。单轴成功后，才更值得投入GPU做大规模并行和域随机化。

## 4. 下一阶段的硬验收

- 每轴至少一条固定初态、全程合法、90°±5°、低速三点支撑保持1秒的轨迹；再检查扰动初态复现。
- 学习策略分别在每轴100个未用于选模的初态上测试，完整成功率≥90%；保留30°/60°、接触力、支架碰撞、穿透和掉落指标。
- 连续动作不重置物理状态、不累积理想姿态漂移，单独报告串联成功率。
- 若经过更充分的轨迹/握姿搜索仍没有合法路径，应检查机构的可达性和力矩条件，必要时评估腕部自由度或环境辅助；这些改变属于另一项机械方案，不能悄悄混入当前单手固定基座任务。

当前证据支持优先修动作可达范围、握姿与探索方式，尚不足以承诺7自由度手在现有全部约束下必然完成XYZ90。
